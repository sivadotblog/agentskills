# agentskills

Agent skills and plugins by [sivadotblog](https://github.com/sivadotblog). Install
in Claude Code today; other tools are coming. See the
[repo README](https://github.com/sivadotblog/agentskills) for install and
uninstall commands.

## Plugins

### sop-kit

Walks a person through an SOP from start to finish: reads it, loads the skills
it needs, collects every input up front, runs the agent steps itself, and
waits on the person for the rest. Also turns a runbook or wiki page into an
SOP in the first place.

- [Demo: GitHub SSH signing, end to end](sop-kit/demo-github-ssh-signing/) —
  draft a runbook, turn it into an SOP, run it, and see the real transcript.
